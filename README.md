# Viaggi

App di viaggio (PWA) con itinerario, spese, documenti e luoghi vicini. Una pagina iniziale fa scegliere il viaggio.

- `madrid/`: Madrid, 28 dicembre - 2 gennaio
- `amsterdam/`: Amsterdam, 27 - 31 marzo 2027

I dati dei luoghi vicini vengono da OpenStreetMap (© contributori di OpenStreetMap, licenza ODbL).
